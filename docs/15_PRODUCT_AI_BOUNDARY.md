# KNLSOFT aTops · SPACEMON · AI Boundary v0.2 Candidate

## 1. 공개 가능한 현재 경계

| 구분 | aTops | SPACEMON |
|---|---|---|
| 시간 축 | 운영 전·변경 전 | 운영 중 |
| 주 대상 | SQL 품질, 위험, 검증 과정 | DB 성능, SQL 실행, 운영 이상 |
| 주 사용자 | 개발, SQL 품질, DBA, 관리자 | DBA, 운영, 성능 분석가, 관리자 |
| 사용자 질문 | 운영에 반영하기 전에 무엇을 점검해야 하는가 | 지금 성능이 왜 변했고 어디를 확인해야 하는가 |
| 허용된 핵심 설명 | SQL 품질·성능 진단과 개발/운영 비교 지원 | 이기종 DBMS 통합 모니터링, 실시간 성능·SQL 분석, 알림 |
| 현재 금지된 확장 | 자동 튜닝 완료, 자동 승인, 모든 배포 통제 | 자동 원인 해결, 자율 복구, 모든 DBMS 기능 동일 지원 |

## 2. AI 역할 계약

AI는 제품 기능을 대체하는 별도 장식 계층이 아니다. 검증된 데이터와 기존 분석을 바탕으로 사용자의 해석과 개선 판단을 보조한다.

| 단계 | 결정론/제품 기능 | AI 후보 역할 | 사람의 책임 | 공개 조건 |
|---|---|---|---|---|
| Input | SQL, 실행계획, 성능·세션·이벤트 등 수집 | 입력 요약·문맥화 | 데이터 적정성 확인 | 실제 입력 목록과 마스킹 정책 |
| Analyze | 규칙, 비교, 통계, 시계열, 상관 분석 | 패턴 해석·원인 후보·개선 후보 | 분석 근거 검토 | 동작 예시와 한계 |
| Output | 진단 결과, 이벤트, 비교, 이력 | 설명·권고 초안 | 채택/반려/추가 검증 | 출력 스키마와 검토 흐름 |
| Verify | 적용 전후 기준선과 측정 | 결과 설명 보조 | 성능·품질 검증과 승인 | 측정 방법·재현 증거 |

## 3. 제품별 AI 후보

### aTops AI

- VERIFY: SQL 구조·위험 분석, 실행계획 해석, 개선 권고.
- VERIFY/ROADMAP: 수정 SQL 후보 생성.
- OPTION: 내부망/폐쇄망 LLM 구성.
- PROHIBITED: 자동 승인, 무조건 안전한 수정, 100% 정확도.

### SPACEMON AI

- VERIFY: 성능 이상 탐지, 시계열 패턴 분석.
- VERIFY/ROADMAP: 원인 후보 및 확인 순서 권고.
- ROADMAP: 자연어 운영 질의.
- PROHIBITED: 무인 자율 복구, 확정 원인 단정, 자동 변경.

## 4. 교차 제품 경계

### 지금 허용

`aTops는 운영 전 SQL 품질을, SPACEMON은 운영 중 데이터베이스 성능을 다룬다.`

### 검증 전 금지

- 공통 SQL ID로 완전한 폐쇄 루프가 동작한다는 표현.
- 하나의 통합 콘솔·라이선스·데이터 모델을 전제하는 화면.
- SPACEMON 운영 데이터를 aTops 개선·배포로 자동 환류한다는 표현.
- 두 제품이 모든 개발부터 운영 과정을 자동 수행한다는 표현.

## 5. 제품 설명 템플릿

각 제품 페이지는 다음 순서를 지킨다.

1. 사용자 문제와 적용 시점.
2. 입력 데이터와 지원 환경.
3. 핵심 기능과 사용자 과업.
4. 출력·증거·이력.
5. AI 역할과 비AI 분석의 구분.
6. 사람의 검토·결정.
7. 제한·옵션·로드맵.
8. 실제 화면·문서·사례.
9. 데모에서 확인할 항목.

## 6. Apply Decision

- Apply now: 제품 시간축, 사용자 질문, AI 보조 원칙, 금지 주장.
- Do not apply: 통합 플랫폼·폐쇄 루프·자율 운영 메시지.
- Defer: 세부 모듈, 라이선스, 연계 API, 지원 DBMS별 기능.
- Trigger: 최신 제품 명세, 실제 AI I/O, 배포 구조, 지원 매트릭스 승인.
