# KNLSOFT Product & AI Claim Matrix v0.1

## Status model
- **CONFIRMED**: supported by current official product material
- **VERIFY**: requires current-version evidence
- **OPTION**: requires separate configuration or contract
- **ROADMAP**: future capability only
- **PROHIBITED**: unsupported, absolute, or misleading

## Cross-product claims
- Allowed: aTops supports pre-operation quality; SPACEMON supports in-operation performance.
- Verify: automatic feedback, common SQL identity, unified console or licensing.
- Prohibited: complete end-to-end autonomous operation.

## Safe interim AI statement
