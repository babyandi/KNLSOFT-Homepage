# KNLSOFT Homepage Strategy Brief v0.1

## Purpose
Build a B2B product-marketing website that proves KNLSOFT's DB/SQL expertise and generates qualified SPACEMON and aTops demo and consulting opportunities.

## Primary audiences
1. Financial/public-sector IT executives
2. DBAs and database operations leaders
3. Development and SQL quality leaders
4. Security, audit, procurement, and SI/partner stakeholders

## Positioning
> KNLSOFT is a DB and SQL technology company managing quality before operation and performance during operation.

- aTops: SQL quality and risk management before production
- SPACEMON: database performance and anomaly management during operation
- AI: analysis and decision support built on verified DB/SQL expertise

## Brand promise
Discover problems earlier, understand causes faster, and operate databases more reliably.

## Message hierarchy
- Company: SQL quality through database performance
- aTops: Better SQL is made before operation
- SPACEMON: Read database change in real time
- AI: Add analysis intelligence to proven DB/SQL expertise

## Required impressions
Established, precise, reliable, enterprise-ready, financially credible, responsibly AI-enhanced.

## Main-page persuasion flow
1. Company role and expertise
2. Customer problem
3. aTops value
4. SPACEMON value
5. AI analysis
6. Security and deployment
7. Customers, cases, certifications
8. Supported DBMS and support
9. Demo and consulting

## Current decisions
- Apply now: purpose, audience, positioning, product-role separation
- Hold: unverified AI claims, customer names, performance figures
- Revisit trigger: verified product specifications and approved evidence
